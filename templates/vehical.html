Vehicle Image Classification Using Deep Learning

Vehicle Image Classification is a Computer Vision task in Deep Learning where an AI model automatically identifies and classifies different types of vehicles from an image.

This project uses Deep Learning models, especially Convolutional Neural Networks (CNNs), to process and understand vehicle images with high accuracy.
